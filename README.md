# Null Army Mod

The Null Army Mod is a Fabric mod for Minecraft 1.21.11 that summons the Null Army from Unstable SMP. This mod introduces the Totem of Null, which has the Curse of Vanishing, and summons fake players with black skins, maxed-out Netherite armor, and Netherite swords. These entities are designed to be players, providing a unique and immersive experience in your Minecraft world.

## Install

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/null-army-mod/releases).
2. Place the downloaded JAR file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Obtain the Totem of Null from the Null Army creative tab.
2. Use the Totem of Null to summon the Null Army.
3. Alternatively, use the `/null army` command to summon Null Army members or the `/null army commander` command to summon Null Commanders.
